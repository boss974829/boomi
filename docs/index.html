Bhoomi

A full-HD 3D topographic map of India. Satellite ground, real elevation, and the high places named.

Open on GitHub How to run

Run the map

git clone https://github.com/boss974829/boomi.git
cd boomi
npm install
npm run dev

Then open http://localhost:8080. The interactive map runs on your machine. This page is the public opening link.
